# oop-minibank-25CS110
OOP MiniBank - 25CS110 (Devarsh)
Each Practical_N folder holds the Part A programs (Q1_..., Q2_..., Q3_...).

Compile and run (JDK 17+), from inside a question folder:

javac *.java
java <MainClass>
Packaged programs (Practical_6/Q3, Practical_14/Q2): javac -d out com/*/*.java, then run the main class, e.g. java -cp out com.shop.Main.

Practical_14 tests use JUnit 5 (add the JUnit dependency in your IDE / Codespace).
